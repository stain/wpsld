# Bundled RO-Crate MASP profiles

Profile crates from [RO-Crate MASP](https://github.com/Language-Research-Technology/ro-crate-masp), licensed
Apache-2.0, copied by `scripts/update-masp-profiles.sh` and listed with their
source, commit and SHA-256 in `../masp-profiles.json`:

- `ro-crate.json`: RO-Crate Machine Actionable Profile 0.1.0, from `profiles/ro-crate/profile-crate/ro-crate-metadata.json` at commit [`6d7a018`](https://github.com/Language-Research-Technology/ro-crate-masp/tree/6d7a018baf827b5716d79a17462e3b3edb15725f)

The upstream profiles have no releases yet, so they are pinned to a commit.
To update, run the script with a newer commit and review the changes.
