# PRONOM file formats, DROID signature file V125

`formats.json` is from [PRONOM](https://pronom.nationalarchives.gov.uk/),
The National Archives' registry of file formats: its DROID signature file
V125, <https://pronom.nationalarchives.gov.uk/signatures/DROID_SignatureFile_V125.xml> (SHA-256 `c7c328dd0e131947667e9b94294c5d47e0b6ec8ec3040b7fd542ac605ecc6ec5`).

Changed: only the 2571 file formats are kept, each with its PUID, name,
version, media types and file extensions, as JSON. The byte signatures for
identifying files, and their priorities, are left out.
