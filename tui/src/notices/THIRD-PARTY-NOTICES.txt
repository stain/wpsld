Third-party notices for the wpsld terminal viewer (wpsld-tui)
============================================================================

This file goes with the built wpsld-tui distribution: the zips built from
the source with Gradle. It lists the third-party software they include,
with its licences and notices.

It does NOT describe the wpsld source code or git repository. That is
under the Apache License 2.0, in LICENSE.txt, and does not contain the
software below: the build downloads it as dependencies.

The zips also include a Java runtime (Eclipse Temurin), under the GNU
General Public License version 2 with the Classpath Exception. Its notices
are in the runtime's legal/ folder.

============================================================================

wpsld-tui uses Lanterna, which is free software under the GNU Lesser
General Public License. It is included unmodified, as the module
com.googlecode.lanterna, one of the modules in the runtime image's
lib/modules, so it is not a separate jar. To use a modified or newer
Lanterna with wpsld-tui, put its jar (a module with the same name) in a
folder, and start the viewer with the Java option --upgrade-module-path,
which replaces the module in the image:

    bin/java --upgrade-module-path <folder> \
        -m no.s11.wpsld.tui/no.s11.wpsld.tui.Main CRATE

The source of Lanterna is at the URL above. Its licence is below, together
