# Copy and paste

In a text field, **Edit > Cut**, **Copy** and **Paste** work on text.
Use the usual keyboard shortcuts for your platform.

To copy descriptions, select one or more entities in the **Entities**
list and choose **Edit > Copy**, or right-click and choose **Copy**. Focus
the entity list in this crate or another wpsld window and choose **Paste**.
The copied descriptions are added; their linked entities are not copied
automatically. Select those too if they are needed. Read any warning about
missing or possibly different referenced entities and review the links.

Local `#` identifiers that are already in use get new identifiers. If an
absolute identifier or file path already exists with different details,
wpsld offers **Merge** or **Keep Existing**. Merge only descriptions of
the same thing. Identical existing descriptions are not added again.

To link to one copied entity rather than duplicate it, paste into a
reference field: wpsld inserts its identifier. This does not copy the
description into another crate. Other wpsld text fields do not paste a
copied entity as text.

**Paste Special** is planned but is not yet available. For now use Paste,
and use **Edit > Undo** if the result is not what you intended.
