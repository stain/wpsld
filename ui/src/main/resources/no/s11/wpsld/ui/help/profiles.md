# Profiles

A profile describes expectations for a particular kind of RO-Crate. In wpsld
it changes which fields are shown as required or suggested in the editor.
The core RO-Crate profile is available by default.

Choose a profile in the toolbar, or use Load profile to add one. A profile
can help guide your description, but selecting one does not by itself
guarantee that the crate meets all of its requirements.
